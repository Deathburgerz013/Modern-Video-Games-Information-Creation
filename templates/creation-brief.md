# Creation Brief: [working title]

## Desired experience

What should the player feel, learn, notice, master, and remember?

## Player verbs

What can the player repeatedly do? Which verbs create meaningful decisions rather than animation alone?

## Core circuit

```text
action → feedback → consequence → new decision → progression → changed action
```

## Selected mechanic records

For every selected mechanic, state why it belongs and which evidence supports that choice.

## Required system graph

List dependencies in implementation order. Mark systems that can be mocked for the first test.

## Content requirements

Rooms, enemies, weapons, rewards, encounters, narrative fragments, art, animation, sound, music, interface, accessibility, and save data.

## Vertical slice

Describe one complete circuit containing every pillar at representative quality.

## Stop conditions

- Do not add content while a core verb lacks readable feedback.
- Do not expand a system that players consistently ignore.
- Do not retain a mechanic solely because another successful game uses it.
- Revise when the observed player behavior differs from the intended behavior.
