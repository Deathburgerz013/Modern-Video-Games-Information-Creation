# Environment Convergence Contract v1

**Status:** first executable functional geography

This pass converts the accepted painted relationships into an original playable greybox. It does not claim an exact terrain reconstruction or final art.

## Construction invariant

Every region must provide:

`landmark -> traversal condition -> useful resource or knowledge -> danger -> reason to return -> readable exit`

Mechanical references are studied for behavior only. No proprietary code, terrain, assets, maps, dialogue, or distinctive content is copied.

| Western islets | storm-side silhouettes | future boat/swim gate | navigation and bounded caches | surf and landing conditions | expedition chain |

## Current executable boundary

The pass establishes recognizable connected regions, physical height, water gaps, route gates, and diagnostic labels. It retains the project shell's player controller, day/night cycle, water plane, and fall recovery.

It does not yet claim gathering, survival meters, swimming, tides, weather simulation, enemies, resources, building, notebook behavior, or final terrain.

## Admission test

Retain a region only if a player can state where it is, how it differs from adjacent space, and why a future survival system would require returning there. Reject geometry that exists only to fill distance.
